# Paradise Nursery Shopping Application

## Project Overview

Paradise Nursery is an online plant shop where customers can browse houseplants, view product details, and manage their shopping cart.

## Features

- Browse houseplants by category.
- View plant images, names, descriptions, and prices.
- Add plants to the shopping cart.
- Increase or decrease product quantities.
- Remove products from the cart.
- Calculate the total cost dynamically.

## Technologies

- React
- Redux Toolkit
- JavaScript
- CSS
